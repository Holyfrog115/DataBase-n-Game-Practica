# База Данных Управляющей Компании и Сапер

Проект создан для летней практики в ВУЗе.

## Функционал

### Модуль «База данных»
Предназначен для управления структурированными данными о жилых домах.
 -  **Два режима работы:** Гостевой (только просмотр и поиск) и Режим Администратора (полный доступ к редактированию);
 -  **Управление данными:** Добавление записей с валидацией входных данных, удаление (поодиночке или интервалами по ID), редактирование существующих строк;
 -  **Умный поиск:** Фильтрация информации с использованием фильтров;
 -  **Безопасность данных:** Автоматическое предупреждение о сохранении изменений при закрытии файла или выходе из приложения.

### Модуль «Сапер»
Классическая головоломка для перезагрузки между работой с данными.
 - Поле 10x10 клеток, 15 случайно распределенных мин;
 - Первый клик всегда безопасен и открывает пустую область;
 - Встроенный таймер, счетчик оставшихся флагов и кнопка быстрого рестарта.

## Запуск и использование

### Для полноценного функционирования программы требуется:
 - ОС Windows XP SP3 или выше;
 - Оперативная память 20МБ или выше;
 - Жесткий диск: 2МБ для хранения программы; дополнительное место для хранения вводимых в базу данных;
 - .NET Framework версии 2.0 или выше;
 - Наличие мыши (или её аналоги), клавиатуры, монитора;
 - Разрешение экрана 1024 x 768 или более. 

### Быстрый старт (Руководство пользователя)

1. **Запуск:** Дважды щелкните по файлу `DBnGame.exe` и выберите режим: **«База данных»** или **«Сапер»**.
2. **Работа с БД:**
   - Нажмите **«Открыть БД»** (для выбора существующего `.txt` файла) или **«Создать БД»**.
   - После загрузки имя файла отобразится в статус-баре снизу.
3. **Режим Администратора:**
   - Чтобы изменять данные, нажмите **«Войти в режим администратора»** и введите учетные данные.
   - После этого разблокируются кнопки: *«Ввод строк»*, *«Удаление строк»* и *«Корректировка полей»*.
   - При вводе некорректных данных приложение подсветит ошибки красным восклицательным знаком с подсказкой при наведении.
